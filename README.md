# 美光台灣工會輿情追蹤 Dashboard

公開新聞資料的靜態 GitHub Pages 儀表板。

## 內容

- 公開新聞的發布時間、第一次加入追蹤列表時間、最後確認時間
- 列表預設依新聞發布時間由新到舊排列；加入列表時間另行顯示
- 主題分布
- 可搜尋、依日期／語言／狀態篩選的新聞清單
- 原始新聞網址
- 同稿轉載標記

## 狀態說明

- **已納入追蹤／曾列入報告**：已經存在於基準清單或先前報告，不代表是本輪新增。
- **同稿轉載／不另重複**：該媒體有刊登，但內容與另一個原始來源高度相同；保留作為媒體覆蓋紀錄，不另計為獨立新聞。
- **報告時段外發現／不寄送**：在 24 小時搜尋回看中被找到，但發布時間不在當次 email 報告時段；保留作為稽核與去重紀錄，不列入該次寄信。

## 資料邊界

本 public repository 只包含公開新聞 metadata 與統計圖表，不包含：

- 工會信箱或寄信紀錄
- API keys、tokens、密碼或其他 secrets
- 會員資料
- 未公開訪談內容
- 調解策略或內部備註

資料由 private monitor 專案產生 sanitized export 後更新。網站是公開頁面，內容僅供新聞追蹤與研究參考。
